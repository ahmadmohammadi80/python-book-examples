# کدهای همراه کتاب «آموزش برنامه‌نویسی با پایتون: از مبانی تا پروژه‌های کاربردی»

این مخزن مکمل آموزشی کتاب فارسی «آموزش برنامه‌نویسی با پایتون: از مبانی تا پروژه‌های کاربردی» است. شامل **۹۰ فایل مثال و تمرین از ۳۰ فصل** و **چهار برنامه نمونه کامل** در پوشه `projects/` است.

> این مخزن مستقل است و وابستگی یا تأیید رسمی Python Software Foundation را ادعا نمی‌کند.

## شروع سریع

- پایتون **3.12 یا جدیدتر** نصب کنید: https://www.python.org/downloads/
- فایل‌ها را با گزینه **Code → Download ZIP** دریافت و استخراج کنید یا مخزن را clone کنید.
- ترمینال را در پوشه اصلی پروژه باز کنید و اجرا کنید:

```bash
python chapters/ch01_example01.py
python chapters/ch01_practice.py
```

اگر `python` روی سیستم شما شناخته نشد، در ویندوز از `py` یا در لینوکس/macOS از `python3` استفاده کنید.

## بسته‌های اختیاری

بیشتر نمونه‌ها فقط با کتابخانه استاندارد Python کار می‌کنند. نمونه‌های مرتبط با Flask، FastAPI و pandas ممکن است به نصب کتابخانه اضافی نیاز داشته باشند. می‌توانید یک محیط مجازی بسازید:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate
python -m pip install -r requirements-optional.txt
```

نصب وابستگی‌ها اختیاری است؛ برای شروع و اجرای نمونه‌های فصل‌های مقدماتی ضروری نیست.

## بررسی کدها

برای بررسی نحوی همه مثال‌ها، بدون اجرای آن‌ها:

```bash
python -m compileall -q chapters projects
python -m unittest discover -s tests -v
```

این بررسی **به‌معنای آزمون کامل عملکرد همه مثال‌ها نیست**. برخی نمونه‌ها تعاملی هستند یا به وب/بسته ثالث نیاز دارند.
